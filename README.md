# Customer Shopping Behavior Analysis

## Project Overview
An end-to-end data analytics project analyzing customer shopping behavior to identify purchasing patterns, customer segments, product preferences, and subscription trends.

## Business Objective
Understand how customer shopping data can help improve customer engagement, loyalty, and marketing and product strategies.

## Tools & Technologies
- **Python:** Pandas, NumPy, data cleaning and exploratory data analysis
- **SQL:** PostgreSQL, aggregations, subqueries, CTEs, and window functions
- **Power BI:** Interactive dashboard and data visualization
- **Git & GitHub:** Version control and project documentation

## Project Workflow
1. Cleaned and prepared the dataset using Python.
2. Handled missing review ratings and engineered additional features.
3. Analyzed customer behavior using SQL queries.
4. Created an interactive Power BI dashboard.
5. Documented findings and business recommendations.

## Business Questions
- How does revenue differ by gender and age group?
- Do subscribers spend more than non-subscribers?
- Which products receive the highest ratings?
- Which products rely most on discounts?
- How do customer loyalty and repeat purchases relate to subscriptions?
- How do Standard and Express shipping customers compare?

## Key Recommendations
- Encourage subscriptions through exclusive benefits.
- Reward repeat customers through loyalty programs.
- Review discount strategies to balance sales and profitability.
- Promote highly rated and popular products.
- Target marketing campaigns using customer segment and revenue insights.

## Project Files
- Python notebook: data cleaning and exploratory analysis
- SQL script: business analysis queries
- Power BI file: interactive dashboard
- Dataset: customer shopping behavior data
- PDF documents: business problem statement and project report
